# Freight Calculator

Дипломный проект: система автоматизированного расчета стоимости грузоперевозок.

**Стек:** FastAPI · PostgreSQL · Vue 3 · Docker Compose

## Запуск

```bash
cp .env.example .env
docker compose up --build
```

- Backend: http://localhost:8000/docs
- Frontend: http://localhost:5173
